# Backend API

Folder ini disiapkan untuk backend proyek E-Library.

Sebelum implementasi, sepakati bersama kelompok:
- runtime/framework backend;
- base path API;
- model data dan database;
- format respons dan penanganan error;
- strategi autentikasi serta pengelolaan secret.

## Konfigurasi rahasia
Gunakan file `.env` lokal yang tidak di-commit. Sediakan `.env.example` hanya dengan placeholder setelah nama variabel disepakati.

## Cara menjalankan
Akan dilengkapi setelah implementasi backend tersedia.
